# 🛸 天空之城 · 空中浮岛竞速经营

一款以**云海浮岛竞速**为核心玩法的经营模拟游戏。玩家经营一支空中竞速车队，在漂浮于云海的浮岛赛道上逐站参赛，赢取积分与奖金，改装飞艇、招募机师技工、达成赞助目标，向赛季之巅发起冲击。

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务（server:4180 + vite:5204）
```

浏览器访问 **http://localhost:5204** 即可开始游戏。

> 若 5204 端口被占用，Vite 会自动切换到其他端口；后端 API 代理随之生效，无需手动修改。

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Vue 3（`<script setup>`）+ Vite + Pinia |

## 玩法说明

1. **云海航线图**：主场景为云海浮岛赛季航线图，6 座浮岛依次排列。点击浮岛上的 **🚀 开赛** 进入分站竞速。
2. **分段分站竞速**：每站分 **启航段 / 中段云流 / 冲线段** 三段。6 艘飞艇（玩家 + 5 名对手）按各自分段用时推进，右侧 LIVE 榜实时刷新名次；每段发挥都受 **天气、已装备改装、部件健康、机师/技工状态** 共同影响，赛道上会弹出超车与天气事件横幅。
3. **中断续看**：开赛瞬间服务器即生成并落库一份完整比赛记录，动画只播不结算。中途退出或刷新页面后，航线图出现「比赛进行中 · 点击中断续看」浮条，赛站按钮变为 **▶ 续看**，从上次观赛进度继续。
4. **一次结算，杜绝重复**：比赛播完（或点「跳过动画直接结算」）才按该记录发放积分/奖金/磨损/声望与人员经验；结算接口幂等，断线重放、重复点击都不会重复发奖。
5. **历史回放**：赛季之巅抽屉的每场战绩都可 **↻ 回放**，用同一份记录重放全场动画与排名，回放只展示结果、绝不再次结算。被历史修复作废（status=void）的越站记录不会出现在历史战绩中，也不能再结算。
6. **赛季推进**：每站完赛进度条 +1，6 站全部完赛为一季；各岛天气与难度不同（晴/风/雨/雾/雷暴，难度 ★1-★5）。
7. **新赛季衔接**：第 6 站结算后，结算卡弹出**赛季总结**（积分/夺冠/登台/最佳名次）与「进入下赛季」；航线终点另有完季浮条，刷新页面或中途退出也不会停在终点。确认后服务端在一个事务内把老赛季**归档进历届赛季榜**，并按赛季分层重置——**积分、赛站、赛季合约**归零/重开（`team.season+1`），而**资金、声望、飞艇与部件健康、改装件、机师技工（经验/心情）、在履租约（押金/场次/磨损归属）**作为车队跨赛季资产全部保留。老赛季的 `races` / `race_log` / `contracts` 一行不删：历史战绩按赛季分组、回放照常、老比赛重复结算仍幂等；衔接接口本身也幂等（重复点击 / 并发重放只归档一次），比赛进行中拒绝衔接。
8. **机库**：查看飞艇四项性能（速度/转向/加速/耐久）与部件健康度；装备/卸下改装件（引擎/翼板/氮气/龙骨/护甲）；招募机师与技工；部件磨损可花费维护恢复至 100%（排班为租约艇出赛时自有艇封存，不可维护）。
8. **赛事排班**：机库中可为下一站安排出赛阵容——指定**机师**、**技工**（缺省均为自动·最强阵容）与**出赛飞艇**（自动 / 自有艇 / 租赁艇）。排班在**开赛瞬间**解析并快照进比赛记录：比赛发挥、结算时的机师经验/心情变化、部件磨损归属（自有艇或租约）全部以快照为准，赛后改排班不影响已开赛的比赛。排班「租赁艇」但没有在履租约时拒绝开赛；排班「自有艇」时即便租约在履也以自有艇出赛（租约场次与磨损不消耗），可借此把租约场次留给高难度赛站。
9. **飞艇租赁**：赛前可在机库签约租用不同性能的高阶飞艇——签约即按租约扣 **押金 + 租金**（租金不退）；租约期间车队以租赁艇出赛，**比赛磨损记入租约**（自有艇封存不磨损），归还时按「累计磨损 × 费率」从押金中结算退款；租约场次用尽须先归还才能继续参赛，归还结算幂等、不会重复退款。
9. **赛季合约**：赞助不再是单一的「积分达标」，而是服务端可配置的**赛季合约**。每份合约由若干条款组成，按本赛季已结算比赛的**天气、最终名次、出赛艇（自有/租赁，租赁可指定艇型）**等条件累计进度，条款之间支持「全部达成」或「达成任意 N 条」；全部达成（满足 need）即在结算事务内**一次性兑现**资金与声望（若因越站作废等导致进度跌破门槛则对称冲回），并回放本赛季各站比赛。

## 竞速记录与结算引擎（单一事实来源）

- 开赛后一条 `races` 记录落库，内含三段全部赛艇的分段 pace/用时/入场时间、天气与发挥系数、**改装件快照**、**机师/技工状态快照**、**排班快照**（出赛艇模式与指定人选）、分段事件（超车/天气）以及**预先确定的最终名次与奖励**。
- 动画、LIVE 实时排名、结算卡、历史回放**全部从同一份记录派生**，不存在各算各的导致「画面名次」与「结算名次」不一致的问题。
- 分段 pace：性能四项按段加权合成（启航拼加速、中段拼极速转向、冲线拼极速爆发），再乘 **部件健康系数**（地板 0.62）与 **分段天气系数**（雾/雷暴在中段、冲线段压制更大）；机师胆识提供天气抗性，机师带队加成与技工调校加成作为常数项叠加。
- 对手 AI 同口径计算天气抗性与机师/技工加成，并按赛站难度与随机档位拉开快慢差距：低难度多为教学局，高难度需靠改装与维护争胜。
- **赛事排班**：排班存于服务端单行表 `lineup`（机师/技工缺省为自动·最强阵容；出赛艇 `auto` 有租约即租约艇、`own` 强制自有艇、`rental` 必须租约艇），开赛瞬间解析并快照进记录（指定人员离队等脏数据自动回落，绝不阻塞开赛）；结算时的机师经验/心情、部件磨损归属（自有艇或租约）与合约租赁条款判定全部以快照为准，越站回滚亦按同一快照对称冲回。
- 名次 1-6 对应 F1 式积分（25/18/15/12/10/8）+ 名次奖金；赛后部件按赛道难度与天气磨损，机师经验/心情随之变化。
- 结算走数据库事务并以 `races.settled` 为唯一闸门（事务内二次校验，同步执行下并发重放也只发一次奖），重复请求直接返回同一份结果（幂等）；越站/作废记录（status=void）返回 409，**赛季合约在同一事务内按已结算战绩对账**。
- **赛季合约引擎**：条款为服务端配置（`CONTRACTS`，入库时快照到 `contracts.terms` JSON），进度不入库、始终从本赛季 `status='settled'` 的比赛记录现算——`points` 取赛季积分，`weather`/`rank`/`rental` 按每场的赛道天气、最终名次、开赛租约快照（含艇型 id；老记录无艇型 id 时回查租约行）累计场次，`race` 为「天气+名次+租赁艇必须在同一场同时满足」的复合条款；达成 `need` 条即在结算事务内一次性发放资金+声望（响应 `contractsPaid`，结算卡展示），已兑现但进度跌破门槛则冲回（`contractsRevoked`），天然幂等。启动时另有一次幂等对账兜底老库/注入数据。
- **越站历史修复（启动迁移补偿）**：首个未完成赛站之后的完赛记录一律视为越站，在同一事务内按各场发奖口径回滚积分/奖金/声望、**部件磨损（parts_dur/hp）与机师经验/心情**；磨损归属一律以开赛快照为准——在履租约回滚租约磨损/场次（不动钱），**已归还租约则剔除该场磨损后重算磨损费并补退押金差额**（回写租约行，绝不误扣封存的自有艇），随后删除流水、把记录置为 void 并重置赛站，最后重算赞助对账与赛季名次；修复本身幂等，重启重复执行不会二次回滚或二次补退。

## 比赛相关接口

| 方法与路径 | 说明 |
|-----------|------|
| `GET /api/shop` | 零件商品目录（名称/槽位/加成项/数值/价格均为服务端配置） |
| `POST /api/shop` | 购买零件；**请求体只接受商品 `id`**。价格、属性与加成由服务端按目录核定，客户端提交的 `price/bonus/stat/slot/name` 一律忽略；编号非法返回 400，扣款与入库在同一事务内完成 |
| `GET /api/rentals` | 租赁艇型目录 + 当前租约 + 最近归还记录（性能/押金/租金/场次/费率均为服务端配置） |
| `POST /api/rentals/rent` | 签约租艇；**请求体只接受艇型 `id`**。费用与性能由服务端按目录核定；同一事务内校验「无在履租约 → 资金 → 扣押金+租金 → 建约」，已有租约或比赛进行中返回 409 |
| `POST /api/rentals/return` | 归还结算：磨损费 = 累计磨损 × 费率，退款 = 押金 − 磨损费（下限 0）；以 `status='active'` 为唯一闸门，幂等，重复请求返回同一份结果、绝不二次退款；比赛进行中返回 409 |
| `GET /api/lineup` | 当前赛事排班 + 下一站实际出赛阵容（机师/技工/出赛艇，含自动回落标记与缺租约警告） |
| `POST /api/lineup` | 更新排班；**请求体只接受 `pilotId` / `mechanicId` / `shipMode`**（省略的字段保持原值，`null` = 恢复自动）。人员 id 必须在车队名册中，否则 400；`shipMode` 仅接受 `auto`/`own`/`rental`。排班在开赛瞬间快照进比赛记录，赛中修改只影响下一站 |
| `POST /api/races/start/:cid` | 开赛并生成完整比赛记录（含排班快照 `factors.lineup`）；该站已有 running 记录时返回同一份（续看）；排班指定租赁艇但无在履租约、或出赛租约场次用尽时拒绝开赛 |
| `GET /api/races/:id` | 读取单场比赛记录 |
| `POST /api/races/:id/progress` | 上报观赛进度（秒），中断续看锚点，与结算无关 |
| `POST /api/races/:id/settle` | 按记录结算，幂等；只发一次奖；作废/越站记录返回 409；租约艇出赛时磨损与场次记入租约而非自有艇；同事务对账赛季合约，响应带 `contractsPaid`/`contractsRevoked`（当场一次性兑现/冲回的合约）；6 站全部结算后 `seasonComplete=true` |
| `POST /api/seasons/advance` | 新赛季衔接（仅 6 站全部结算后可调）：同事务归档老赛季最终战绩到 `seasons` 排行榜、`team.season+1`、积分/车队名次归零、赛站重新开放、按配置为新赛季重签一套合约；**老赛季 races/race_log/contracts 原样保留**（历史回放不丢），资金/声望/飞艇/改装/人员/租约保留。幂等（以 `seasons` 归档行为唯一闸门），比赛进行中返回 409，未完季返回 409/400；响应 `summary` 为老赛季归档摘要 |

## 数据表（SQLite）

`team` 车队资金/声望/赛季积分（`season_pts/season_pos` 仅当前赛季，衔接时归零） · `airships` 飞艇属性与部件健康 · `pilots` / `mechanics` 人员 · `upgrades` 改装件 · `circuits` 浮岛赛道（`finished/rank` 每赛季重置，天气/难度配置固定）· `contracts` 赛季合约（按 `season` 分层：每季一套，条款 terms JSON 快照、need、奖励、earned/paid_at 兑现状态；进度不入库，按该赛季已结算比赛现算；老合约行归档保留） · `seasons` 历届赛季档案（一季一行：最终积分/奖金/声望/夺冠/登台/最佳名次/车队名次，排行榜的单一事实来源，衔接时归档、不随后续赛季变化） · `rentals` 飞艇租约（艇型性能与费用快照、累计磨损/已用场次，跨赛季保留；active→returned 含结算退款）· `lineup` 赛事排班（单行：下一站机师/技工/出赛艇模式，开赛时快照进比赛记录）· `races` 比赛记录（分段过程/快照/奖励，按 `season` 归属；running→settled，越站作废为 void；含观赛进度 watch_el 与作废时间 voided_at；老赛季记录原样保留供回放）· `race_log` 结算流水（按 `season` 归属，经 `race_id` 关联到对应比赛）
